🖨️ Elgin I9 — Ajuda 

    
Binário Go único (CLI + API + Web UI). Envia ESC/POS direto para a térmica — sem driver, sem spooler no Linux.


    
Endpoints

    

      
RotaO que faz

      
GET /healthstatus da impressora (device, ok)

      
POST /printimprime um cupom (corpo JSON, abaixo)

      
POST /feedavança papel — corpo {"linhas": N}

      
POST /cutaciona a guilhotina

      
GET /pingimprime "pong" (com respiro de 3 linhas)

      
GET /qrgera um QR como PNG (sem imprimir) — ?text=…&tamanho=1..8

    


    
Campos de cada linha do /print

    

      
CampoValores

      
textoaté 48 caracteres (24 na fonte larga); quebra sozinho

      
alinhamentoesquerda | centro | direita

      
fontenormal | larga (2x, títulos)

      
negritotrue/false

      
linhatrue repete o texto até o fim (moldura)

      
tipotexto (padrão) | imagem | qr

      
imagembase64 (PNG/JPEG/GIF, com ou sem prefixo data:) — só para tipo=imagem

      
qrconteúdo do QR (URL/texto) — só para tipo=qr

      
qr_tamanhomódulo do QR 1..8 (padrão 4) — só para tipo=qr

      
compactglobal: true/ausente = corte rente; false = respiro de 3 linhas

    


    
Dicas

    
    
      
  • No bloco de lista, Enter ou Tab cria o próximo item com foco; a lista nunca fica vazia.
    • 
      
  • Para adicionar uma imagem, use o botão 🖼️ Imagem (escolhe arquivo) ou Ctrl+V com uma imagem na área de transferência.
    • 
      
  • Imagem e QR são convertidos para 1-bit (dither) e ajustados à largura do papel (576 dots); QR maior que o papel reduz o módulo automaticamente.
    • 
      
  • A linha pontilhada com  no preview mostra onde a guilhotina corta.
    • 
      
  • Emojis e a faixa baixa (☺♥♦♣♠) não existem na fonte da i9 — viram ?.
    • 
      
  • Impressora: Linux detecta a Elgin por USB ID (20d1:7008); Windows usa a fila padrão ou ELGIN_LP.
    •
